# Proposal

## Why

Jenny's September21 16:19-16:26 direction supersedes the fixed clearing/board:
start in lush woodland, choose and chop a building site, and explore seeded
terrain that remembers changes. Candidate02's actual09:59 image exposes the
finite terrain edge. Another cosmetic skirt would not deliver this request.

## What Changes

- Reuse procedural meshes, admitted woodland assets/LODs, existing resource
  harvest/clear/build/plot authority and save wrapper.
- Add a small portable seeded generator, bounded moving chunk caches and sparse
  persistent resource edits. Generate all actionable resource identities.
- Remove the fixed house clearing and80m edge rails. Keep minimal spawn safety,
  actual occupied/cleared sites and coherent stream access.
- Render dense standing woodland and layer cover with trees, not a radial ring.
  Standing playable trunks are reachable, tool-gated and permanently fellable.
- Introduce an explicit current-generation save schema/fresh test profile.
- Stage large mountains, regional drainage/rivers/lakes as later work; no voxel
  digging, unlimited-state promise, legacy-seed migration or engine rewrite.

## Capabilities

### New Capabilities
- `persistent-generated-woodland`: seeded chunk exploration and remembered
  woodland edits with integrated visual/gameplay acceptance.

### Modified Capabilities
None. Existing asset-quality requirements remain in
`upgrade-woodland-environment-assets`.

## Impact

Portable generation and simulation/save authority; World/Controller/save wrapper,
terrain/collision/resource rendering and targeted engine routes. Current selected
navigation06 remains until a real navigable, visually improved candidate passes.
