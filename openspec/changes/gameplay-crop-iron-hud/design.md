# Design

- Rules live in `Simulation/HomesteadToolUpgrades`; the shop row, the toast and `ShopBuyToolUpgrade` only present them. The tier is per tool type, so one purchase upgrades the tool wherever she keeps it, but she must hold the crafted tool (pack or chest).
- Iron's benefit already exists in the overgrowth tables (energy x0.85, fewer swings on stumps, rocks, thickets); this change adds no new tier effects.
- Only worn-to-iron is sold; steel and master-forged wait for mining.
