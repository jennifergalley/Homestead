# Spec Delta

## ADDED Requirements

### Requirement: A dark parchment palette is offered without changing layout
The menus SHALL support a dark parchment palette that changes colours only, keeps layout, type, shapes and icons, and keeps body and accent text at 4.5:1 contrast or better; the light parchment SHALL remain selectable in Settings.

#### Scenario: Switching palettes
- **WHEN** she switches between light and dark parchment in Settings
- **THEN** only the colours change and every label stays readable
