# S09 - Poly Haven public metadata schema

URL: https://api.polyhaven.com/api-docs/swagger.json
Accessed: 2026-09-20 by the ground/sky worker.
Type: primary machine-readable public API documentation.

## Short verbatim evidence

"An array with the dimensions of this asset on each axis in millimeters."

## Interpretation

Dimension values in selected asset metadata can be converted to metres by
dividing by 1000. This is the API's intended unit, not a guarantee of scan accuracy
or a promise that imported mesh units/pivots match Unreal centimetres.

Credibility: high for metadata semantics. Recency: live, revision date unknown.
Bias: low promotional bias; implementation metadata remains subject to correction.
