## Maps and dependency handling

All selected maps have the requested measured dimensions:2048x2048 tree/ground,
1024x1024 fern/grass. Most PNGs are16-bit. Tree branch diffuse and roughness are
8-bit RGBA; leaf/grass diffuse are16-bit RGBA with varying embedded alpha.
Fern diffuse is16-bit RGB and needs its separate alpha map. The separate tree
leaf/fern/grass alpha PNGs are16-bit grayscale with decoded ranges0-65535;
these are masks, not an embedded alpha channel.

Tree branch embedded alpha ranges are near opaque (8-bit decoded237-255 in
diffuse/roughness), unlike leaf/grass cutout masks. Do not indiscriminately wire
every map's alpha as identical foliage coverage. Pillow downconverts multichannel
16-bit PNGs for decoded extrema, so the inventory reports the authoritative
IHDR bit depth separately. No channel repacking, normal conversion, source
resizing or pixel modification occurred.

The FBX contains40 tree and16 grass filename/reference fields, including author
absolute paths and `..` relative paths. They were **recorded only**, never
resolved/opened. Fern has no serialized Texture/Video objects despite advertised
map dependencies. The manifest preserves the advertised GL/EXR dependencies
but intentionally selects explicit DX normals/PNG maps for future reviewed
material wiring. Automatic source-path lookup is not an approved importer.
